## About

I build projects that connect usable interfaces with local data, automation logic, sensors, camera input, and hardware-aware workflows. My strongest work is around Python desktop applications, computer vision prototypes, Arduino-based automation, and practical student or operator tools.

## Featured Work

1. **DiscoBuddy** - Private operator workflow desktop app using Python, PySide6, SQLite, scanner-style input flows, and packaged deployment.
2. [**IntelligentVisualInspectionSystem-IVIS**](https://github.com/Leuename/IntelligentVisualInspectionSystem-IVIS) - Public visual inspection system using Python, PySide6, OpenCV, YOLO, SQLite, and Arduino serial control.
3. [**FIRE-AND-SMOKE-DETECTION-WITH-AUTOMATED-FIRE-SUPPRESSION-USING-IMAGE-PROCESSING-AND-MACHINE-LEARNING**](https://github.com/Leuename/FIRE-AND-SMOKE-DETECTION-WITH-AUTOMATED-FIRE-SUPPRESSION-USING-IMAGE-PROCESSING-AND-MACHINE-LEARNING) - Public fire and smoke detection prototype with image processing, machine-learning detection, and automated suppression control.
4. **StudentInformationSystem** - Private PySide6 and SQLite desktop CRUD application for student record management.
5. [**Automated-Water-Level-Detection-System-with-SMS-Alert-Notification**](https://github.com/Leuename/Automated-Water-Level-Detection-System-with-SMS-Alert-Notification) - Public Arduino water-level monitoring prototype with GSM SMS alert notifications.
